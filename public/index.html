How do I run a bot?

How to Run Your Discord Bot

  1. Go to the Discord Developer Portal and select your bot application or create one.
  2. Go to the Installation tab:
    • Under Installation Contexts, uncheck User Install and leave only Guild Install checked.
    • Set Install Link to None.
  3. Next, go to the Bot tab, make it private, then scroll to Privileged Gateway Intents and enable all three intents: Presence Intent, Server Members Intent, and Message Content Intent.
  4. Reset bot token under Token and copy it.
  5. Go to OAuth2 → URL Generator, choose the bot scope.
  6. For Bot Permissions, select Administrator.
  7. Copy the generated invite URL and open it in a browser to invite your bot to your server.
  8. Enter the copied token and press 🚀 Start Bot.
