How to Run Your Discord Bot

  1. Go to the Discord Developer Portal and select your bot application or create one.
  2. Go to the Bot tab, then scroll to Privileged Gateway Intents and enable all three intents: Presence Intent, Server Members Intent, and Message Content Intent.
  3. Next, go to the Installation tab:
    • Under Installation Contexts, uncheck User Install and leave only Guild Install checked.
    • Set Install Link to None.
  4. Go to OAuth2 → URL Generator, choose the bot scope.
  5. For Bot Permissions, select Administrator.
  6. Copy the generated invite URL and open it in a browser to invite your bot to your server.
  7. Back in Discord, type /active to use the bot's command. If the command doesn't appear, refresh Discord.
